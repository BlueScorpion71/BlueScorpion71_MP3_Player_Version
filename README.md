# BlueScorpion71 MP3 Player

## Version 2.0

This repository contains the public version information used by the **BlueScorpion71 MP3 Player** to check for available updates.

### Purpose

The player reads the `version.json` file from this repository to determine the current available version and update information.

### Version 2.0

- Installation and uninstallation workflow fixed and tested.
- The player closes cleanly when the uninstaller is started.
- The uninstaller continues correctly after closing the player.
- User data deletion remains optional.

### Important

This repository contains **only public version and update information**.

The source code and development files of the BlueScorpion71 MP3 Player are **not stored in this public repository**. The source repository remains private.

### Update information

The current version is defined in:

`version.json`

The download location is provided there as `download_url`.
